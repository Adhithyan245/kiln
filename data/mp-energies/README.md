# Energies-only Materials Project cache

One gzipped JSON file per chemical system: 2,745 systems. The first 2,524 are every candidate pair system of the 159 precursors in `data/precursor_props_extended.csv` (the first 702 of them are the pair systems of the study's 46 precursors). The other 221 are the systems that recipes of one or three to five precursors need for 64 widely made materials, among them battery cathodes (NMC, NCA, LFP, LMO), solid electrolytes (LLZO, LATP), superconductors (YBCO, BSCCO), perovskites (BST, PZT, LSCF, LSM), garnets and phosphors, and the benchmark's single- and multi-metal targets. Other systems are fetched on demand when the server has `MP_API_KEY`. Each entry keeps only composition, uncorrected energy, MP2020 correction and Materials Project id: no structures. The original 702 were written by `python -m kiln.recipe --compact-cache` from `cache/mp/`; the other 1,822 were fetched in the same form (GGA/GGA+U thermo type, all subsystems) with `mp_api`. `kiln.recipe` reads `.json` and `.json.gz` alike, and the screen gives the same results from this cache as from the full one. The MACE check needs the full cache, which is not committed.

Data from the [Materials Project](https://materialsproject.org) (A. Jain et al., APL Materials 1, 011002, 2013), licensed CC BY 4.0. Used here for the post-study recipe finder only.
