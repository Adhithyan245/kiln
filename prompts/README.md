# First prompts

1. Clone the repo and check out `dev` (the default branch).
2. Open your coding assistant **in the repo folder** so it loads the project rules (Claude Code: `CLAUDE.md`; Codex: `AGENTS.md`; Gemini CLI: `GEMINI.md`).
3. Paste your file below. Each prompt asks the assistant to plan first and wait for your OK.
4. Do one task at a time, check its "done when", commit, `git pull --rebase`, then `git push` to `dev`.

The tasks follow the Team split in the plan. Later tasks are listed so you know what's next, but paste them one at a time.
